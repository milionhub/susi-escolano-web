# Susi Escolano — Web Corporativa

Web corporativa desarrollada para **Susi Escolano SL**, empresa especializada en reformas, interiorismo, licencias y tasaciones.

El proyecto fue diseñado y desarrollado desde cero con el objetivo de crear una presencia digital moderna, responsive y orientada a la captación de clientes, combinando una experiencia visual cuidada con rendimiento y SEO técnico.

## 🌐 Web

**[Visitar susiescolano.com](https://susiescolano.com)**

## ✨ Características principales

- Diseño responsive adaptado a móvil, tablet y escritorio.
- Arquitectura basada en componentes reutilizables.
- Animaciones e interacciones para mejorar la experiencia de usuario.

## 🏗️ Arquitectura

El proyecto utiliza **Next.js con App Router** y una arquitectura basada en componentes reutilizables.

La interfaz se divide en diferentes secciones independientes que permiten mantener una estructura modular y facilitar la evolución del proyecto.

Entre las principales secciones se encuentran:

- Hero
- Servicios
- Proyectos
- Proceso de trabajo
- Antes / Después
- Sobre nosotros
- Contacto
- Footer

Los componentes compartidos y elementos de interfaz se reutilizan para mantener consistencia visual y reducir duplicación de código.

## 🎨 Diseño y experiencia de usuario

La interfaz fue diseñada buscando transmitir una imagen profesional y premium acorde con el sector de reformas e interiorismo.

Se trabajaron especialmente:

## 🚀 Ejecución local

Clona el repositorio:

```bash
git clone <URL_DEL_REPOSITORIO>
cd <NOMBRE_DEL_REPOSITORIO>
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```

La aplicación estará disponible en:

```text
http://localhost:3000
```
