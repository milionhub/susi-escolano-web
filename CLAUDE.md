# Proyecto: Susi Escolano SL

Web one-page premium para empresa familiar de reformas, proyectos e interiorismo.

## Objetivo

Crear una landing moderna, elegante, visual y enfocada a captar clientes mediante WhatsApp, teléfono o formulario de contacto.

La web debe transmitir confianza, calidad, cercanía y profesionalidad, evitando parecer una web genérica de reformas.

## Stack

- Next.js
- TypeScript
- Tailwind CSS v4
- Framer Motion
- shadcn/ui
- lucide-react

## Tipo de web

Landing one-page con navegación por anclas.

No crear varias páginas independientes salvo que se solicite expresamente.

## Secciones principales

1. Hero principal
2. Sobre nosotros
3. Servicios
4. Proyectos destacados
5. Antes / Después
6. Proceso de trabajo
7. Por qué elegirnos
8. Testimonios
9. Contacto

## Estilo visual

- Premium
- Minimalista
- Cálido
- Elegante
- Visual
- Tipo estudio de arquitectura/interiorismo
- Mucho espacio en blanco
- Imágenes grandes
- Tipografía cuidada
- Animaciones suaves
- Diseño mobile first

## Branding

Empresa: Susi Escolano SL  
Sector: reformas, interiorismo y proyectos  
Zona: Elche, Alicante, Santa Pola y alrededores  
Tono: cercano, profesional y elegante

## Reglas de diseño

- Evitar diseños genéricos o de plantilla básica.
- Evitar exceso de texto.
- Priorizar fotografías reales de proyectos.
- Usar secciones amplias y limpias.
- Mantener coherencia visual en colores, espacios y tipografía.
- Usar animaciones sutiles, no exageradas.
- La web debe parecer de un estudio premium, no de una empresa barata.

## Reglas técnicas

- Código limpio y reutilizable.
- Componentes separados por secciones.
- Mobile first.
- Responsive perfecto.
- Accesibilidad básica correcta.
- SEO local básico.
- Usar TypeScript correctamente.
- No instalar librerías innecesarias.
- No romper la estructura del proyecto.
- Antes de cambios grandes, explicar brevemente el plan.

## CTA principal

El objetivo principal es que el usuario pida presupuesto.

CTAs recomendados:

- Solicitar presupuesto
- Hablar por WhatsApp
- Ver proyectos
- Contactar
